# STEP 1: サービスA(飲食店特化版)を作る

## 1-1. サービスタイトル(25字以内)
```
飲食店向けに更新できるHPを作ります
```

## 1-2. タイトル補足説明/キャッチコピー(15〜30字)

## 1-3. サービス内容(1,500字以内)
```
【お悩み】
・ホームページを作りたいが、何十万円もの制作費は出せない
・SNSだけでは営業時間やメニューが新しいお客様に伝わりにくい
・せっかく作ってもらっても、写真やメニューを変えるたびに追加費用がかかるのは避けたい

【解決策】
AIとノーコードツールを組み合わせて、制作費を抑えながらスマホ対応のホームページを短納期でお作りします。納品後はご自身で写真やメニューを更新できる形でお渡しするので、更新のたびに追加費用がかかる心配もありません。

■このサービスでできること
飲食店(カフェ・居酒屋・ラーメン店など)向けに、スマホ対応の1ページ完結ホームページを制作します。ノーコードツールで制作するため、納品後は写真やメニューの差し替えをご自身で行っていただけます(操作マニュアル動画付き)。

■作業内容
・トップページ、メニュー、アクセス、SNS導線の設置
・AIを活用したキャッチコピー、メニュー紹介文の作成サポート
・納品後にご自身で更新できる構成と、操作マニュアル動画のお渡し

■私について
Web制作の実務経験があります(飲食店向けシステム開発に携わった経験を含みます)。現場でどう使われるかを踏まえた導線設計を心がけています。

■ご注文までの流れ
1. まず「見積り相談」からお問い合わせください(業態、メニュー数、お好みのイメージ等)
2. 内容確認後、正式にご購入いただきます
3. 構成案とデザイン案をご提示します(3営業日が目安です)
4. 軽微な修正は3回まで無料で対応します
5. 納品と操作マニュアル動画をお渡しします

■納品後について
納品後1週間はサイトに関するご相談を無料で承ります。継続的な更新をご希望の場合は、有料オプションの更新代行や保守サポートをご利用ください。

■現在、初回限定価格でご案内しています
出品したばかりのため、先着3名様限定の初回限定価格にてご案内しております。制作事例として紹介させていただける方や、感想をお聞かせいただける方を歓迎いたします。
```
