# Winey 無在庫販売の会社比較（2026-10-23 調査）

記号: ✅ 公式ページで確認 / △ 公式以外・古い情報・一部だけ確認 / ❓ 未確認
「無在庫」＝注文が入ってから1枚ずつ作り、会社から購入者へ直接送る仕組み（POD＝プリントオンデマンドとも言う）

## 結論
- **本命は Printful＋BASE**（確信度 中〜高）
  - BASEで売れたら**自動で**作って発送まで進む ✅。自分で発注する手間がない
  - 日本の工場で作れるボディがある（United Athle のスウェットなど）✅
  - 首元のブランドタグも印刷できる ✅
- **ただし、デザイン画のとおりには作れない部分があります**（下の「デザインごとの実現度」）
  - ワッフル生地のヘンリーネックで、ボタンの色・ステッチの色・裾のタグまで指定する作り方は、**どの会社でも見つかりませんでした**
- 予備の候補は2つ
  - **UP-T**: デザインを清書する無料サービスがあり、BASE連携もできる。ただし注文ごとに自分で発注する
  - **SUZURI**: 一番かんたん。ただしBASEではなくSUZURIの中のお店になる

## 3. 「デザインをきれいにしてくれる会社」はあるか
**あります。** ただ、いただいた5枚は**服の完成イメージ図**で、印刷用のデータではありません。

印刷する絵の部分は横150〜500ピクセル程度しかなく、そのまま印刷すると確実にぼやけます（事実）。拡大しても直らないので、**清書（描き直し）が必要**です。

| 頼み先 | 料金 | 特徴 |
|---|---|---|
| UP-T の無料デザインサポート | 同じデザイン3枚以上の購入で無料、2枚以下は1,000円 △ | ラフ画から清書。修正2回まで無料 △ |
| オリジナルプリント.jp のデータ作成サポート | 500円〜／1,000円〜（2022年情報）△ | 手描きの書き起こし、背景消し |
| ココナラ等の個人デザイナー | 数千円〜（❓相場は未確認） | 一番自由に頼める。Printful公式ブログはFiverr（海外版）で1デザイン$35程度を目安にしている △ |
| 自分で（私が手順を案内） | 0円 | 無料ソフトでなぞり直す。文字はフォントで打ち直せる |

**私の提案**: 「Love Peace」「Winey」の文字は、フォント（パソコンの文字）で打ち直せばすぐきれいになります。3人の人物と顔の絵は、元の手描き（紙やiPadの元データ）があれば、それを清書に出すのが一番安くきれいです。

## 4. なぜ Printful＋BASE が本命か（5回の「なぜ」）
1. なぜ Printful？ → BASEで売れたら発注から発送まで**自動**だから
2. なぜ自動が大事？ → あなたの目的は「在庫を持たずに仕組み化」。注文のたびに手で発注する方式（UP-T・オリジナルプリント.jp）は、売れるほど作業が増え、発注忘れで発送が遅れる危険もある
3. なぜ手作業だとダメ？ → 本業や他の仕事と並行するなら、作業時間が利益を削る。小さなブランドでは、お客さんの信頼は発送の遅れ一回で落ちやすい（推測）
4. なぜ BASE？ → 月額0円で、自分のブランドのお店を持てる。SUZURIやBOOTHは「その中の1店舗」になり、ブランドの世界観を出しにくい（推測）
5. なぜ日本製造にこだわる？ → 届くのが早く（最短3日 ✅）、海外発送のような送料・関税の問題が起きにくい ✅

**反対意見（弱点）**
- Printfulの料金は**ドル建て**の表示なので、円安だと原価が上がる（推測・確信度 中）
- 1枚あたりの原価は、まとめて作るより高い（無在庫と引き換え）
- ワッフル生地のヘンリーネックは作れない

**別の案**: 最初はSUZURIで「売れるか」だけを試す（手間ゼロ・0円）→ 売れたデザインをPrintful＋BASEで本格販売、という2段構えもあり。

## 5. デザインで確認が必要なこと
- **5枚目の顔**: 実在の人の写真や、他人が撮った写真をもとにしていると、肖像権（顔を勝手に使われない権利）や著作権（写真を撮った人の権利）の問題になり得る（推測・確信度 中）。あなたが自分で描いた架空の顔なら問題なし
- **「since 1960」**: ブランドが今から始まるのに「1960年創業」と書くと、お客さんに誤解を与える表示と見られる可能性がある（推測・確信度 中。景品表示法などの法律の確認は❓未確認）。家業の歴史など根拠があるなら、その説明をショップに書くと安全
- **「Winey」の商標**: 他社が服の分野（第25類）で登録していないか、[J-PlatPat](https://www.j-platpat.inpit.go.jp/) で確認するのがおすすめ。登録状況は❓未確認
- **3人の人物**: ドレッドヘアの踊る人物。特定の有名人を描いたものでなければ問題は小さい（推測）
- ピースマーク・ラスタカラー（赤黄緑）・「one love」は一般的なモチーフ。ただ「ONE LOVE」が商標登録されているかは❓未確認
