# デザインを印刷用データにする

## いまの状況
- 受け取った5枚は `winey/design/original/` に保存済み。ただし**服の完成イメージ図**で、絵の部分の画素が少ないため、そのままでは印刷用にならない（清書が必要。RESEARCH_無在庫の会社比較.md の3章）
- 画像を `winey/design/original/` に入れてもらえれば、下のスクリプトで変換できます。元の画像は上書きしません。

## 使い方（画像が届いたら私＝Claudeが実行します）
```
python3 winey/tools/prepare_print.py winey/design/original/画像の名前.jpg
```
- 出力先: `winey/design/print/画像の名前_print_300dpi.png`
- 確認用: `_preview_on_white.jpg`（白Tに乗せたイメージ）、`_preview_on_gray.jpg`（背景のゴミを探す用）
- 線を真っ黒1色にしたいときは `--mono` を付ける

スクリプトがやること:
1. **診断**: 画素数、ぼやけ具合、影・ムラを表示
2. **背景を透明に**: 紙の白い部分を消す。スマホ撮影の影もならしてから消す
3. **半透明を無くす**: 色のある所は100%、無い所は0%にする
4. **大きさを整える**: 印刷範囲 15×18インチ（約38×46cm）に収まる最大サイズ、300dpi、sRGB で保存

## 用語の説明
| 言葉 | 意味 |
|---|---|
| dpi | 1インチ（2.54cm）に並ぶ点の数。多いほど細かい。300dpiで38cm幅なら約4500点必要 |
| 透明PNG | 背景が透けている画像。これでないとTシャツに白い四角が印刷される |
| sRGB | 色の決まりごとの一つ。Printfulはこれで保存するよう案内している |
| DTG | Tシャツに直接インクを吹き付ける印刷方法。Printfulの通常のTシャツ印刷 |
| ベクター化（トレース） | 写真の線を、拡大してもぼやけない「線の情報」に描き直すこと |

## Printful の入稿ルール（公式で確認できたもの）
| ルール | 内容 | 確信度 | 出典 |
|---|---|---|---|
| 解像度 | 150〜300dpi が理想。アパレルは150dpiで十分、300を超えても良くならない | 高 | [Printful 入稿ガイド](https://www.printful.com/blog/everything-you-need-to-know-to-prepare-the-perfect-printfile) |
| 形式 | PNG または JPEG。背景を透明にするなら PNG | 高 | 同上 / [グラフィックガイド](https://www.printful.com/graphics-and-embroidery-guide) |
| 半透明 | 100%透明は消えるが、中間の透明度は思い通りにならないことがある | 高 | 同上 |
| 色 | sRGB IEC61966-2.1 | 高 | 同上 |
| 印刷範囲 | 12×16インチが基本、一部のDTG商品は15×18インチに拡大中 | 中（商品ごとに違う） | 同上 |
| 容量 | 200MBまで、20,000×20,000px まで | 中 | 同上・ヘルプセンター（検索結果のみ） |
| 線の最低の太さ | DTGの数字は**未確認**。別の印刷方式（DTF）では1pt（約0.35mm）以上 | 低 | [印刷方式の注意](https://help.printful.com/hc/en-us/articles/50264395400337-Disclaimers-for-Printing-Techniques) |

**ご依頼の「300dpi」について**: 300dpiで作るのは問題ありません（スクリプトもそうしています）。ただ、公式はTシャツなら150dpiで十分としています。元の絵の画素が足りないとき、300dpiにこだわって引き伸ばしても線はきれいになりません。

## 手描きの写真で線がぼやけている場合
**拡大しても、ぼやけは直りません**（事実）。拡大は「ぼやけた線を大きくする」だけです。

よくある問題と改善案:
| 問題 | 印刷するとどうなるか（推測） | 改善案 |
|---|---|---|
| 線のふちがにじむ | 線の周りに薄い色のフチが出る | 下の「ベクター化」 |
| 影・紙の色ムラ | 背景にうっすら汚れが印刷される | 明るい窓際で真上から撮り直す／スキャナーで取り込む |
| 斜めから撮影 | 形がゆがむ | 真上から撮る。スキャナーが確実 |
| 画素が少ない（拡大率2倍超） | 全体がぼんやりする | 大きく撮り直す、またはベクター化 |
| 細すぎる線 | かすれる・消える可能性 | 線を太めに描き直す |

おすすめの順番:
1. **まず撮り直し（0円）**: 白い紙、昼の窓際、真上から、影が入らないように。コンビニのスキャン（数十円、要確認）も有効
2. **ベクター化（0円〜）**: 無料ソフト Inkscape の「ビットマップのトレース」で線をくっきりさせる。私が手順を案内できます
3. **人に頼む（有料）**: ココナラ等でトレースを依頼。**お金がかかるので、やるかどうかはあなたが判断**
4. Printful にも、解像度の低い画像をAIで補正する機能（Smart Image Tool）がある（[出典](https://www.printful.com/blog/everything-you-need-to-know-to-prepare-the-perfect-printfile)）。仕上がりはサンプルで確認が必要
