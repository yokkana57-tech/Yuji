# Winey テスト段階の手順

目的: 本格的に売る前に、「このデザインのままで売っていいか」「どこを直すか」を、少ないお金で判断する。

記号: 💰 お金がかかる / 👤 あなたが操作・判断する / 🤖 私（Claude）ができる

## 全体の流れ（4段階）
| 段階 | やること | 費用 | 分かること |
|---|---|---|---|
| 1. データ作り | 印刷できるデータにする | 0円〜 | 絵がきれいに出せるか |
| 2. 画面で試す | Printfulの着用イメージ画像で比べる | 0円 | 大きさ・位置・色の組み合わせ |
| 3. 実物で試す | サンプルを2枚注文 | 💰 約7,700円（仮定） | 生地・色・にじみ・着心地 |
| 4. 人に見せる | 実物と画像を見せて反応を集める | 0円 | 売れそうか、いくらなら買うか |

最後に、決めておいた基準で「販売／修正／やめる」を判断する。

---

## 段階0: 先に決めておくこと（大事）
後で迷わないように、**判断の基準を先に決めます**。テストの後に決めると、自分の作品を甘く見てしまいがちです（推測）。

- [ ] 👤 テストするデザインを**2つに絞る**
  - 私の案: **③ Love Peace（黒スウェット）** と **①② の胸ロゴ（普通のロンT）**
  - 理由1: 大きなプリントと小さなプリント、スウェットとロンTを一度に比べられる
  - 理由2: ⑤（顔のデザイン）は、顔の元になったものの確認が終わってから
- [ ] 👤 合格の基準を決める（下の表の数字は私の案。変えてOK）

| 見るところ | 合格 | 修正 | やめる |
|---|---|---|---|
| 印刷の仕上がり | 線がくっきり、色も想像どおり | 一部がにじむ・色が違う | 全体がぼやける |
| 生地 | 自分が普段から着たいと思える | ボディを変えれば良くなる | どのボディでもダメ |
| 洗濯3回後 | ひび割れ・色落ちがほぼ無い | 少しある | ひどい |
| 人の反応（10人に見せて） | 3人以上が「この値段で買う」 | 「デザインはいいけど○○なら」が多い | 0〜1人 |

## 段階1: 印刷用のデータを作る（費用 0円〜）
いま持っている5枚は「服の完成イメージ図」で、印刷する絵の部分の画素（点の数）が足りません。**ここを直さないと、サンプルを作ってもぼやけて正しく判断できません。**

- [ ] 👤 **何のアプリで描いたか教えてください**（例: アイビスペイント、Procreate など）
  - アプリの元のファイルがあれば、もっと大きいサイズで書き出せるかもしれません。そうなれば清書は不要です（推測）
- [ ] 🤖 元のファイルが無い場合は清書します
  - 文字（Love Peace／Winey／one love）は、近いフォント（パソコンの文字）で私が作り直せます
  - 3人の人物・ピースマークは、描き直しかトレース（なぞって描き直す）が必要。あなたが自分で描き直すか、外部に頼むか（💰）を決める
- [ ] 🤖 私が透明PNG・300dpiに変換して、背景のゴミが無いか確認

## 段階2: 画面で試す（費用 0円）
- [ ] 👤 Printfulに登録する（登録は無料 ✅。登録の時点でカード情報が必要かは❓未確認）
- [ ] 👤 スウェットのボディを選ぶ（例: United Athle 5044-01）。ロンTは Printstar 00102-CVL など
- [ ] 👤 デザインを置いて、**着用イメージ画像**（モックアップ）を作る
  - 比べるもの: 大きさ（大・中・小）、位置（胸の中央・左胸）、ボディの色（黒・白）
- [ ] 🤖 画像を見せてもらえれば、バランスや見え方について意見を出します
- [ ] 👤 2〜3パターンに絞る

## 段階3: 実物で試す（💰 約7,700円）
- [ ] 👤 サンプルを注文する（カード登録が必要。**注文はあなたが行う**）
  - 【仮定】スウェット 約4,670円＋ロンT 約2,990円＝**約7,660円**。1ドル158円で計算
  - サンプル割引（20%引き）は、ネットショップ連携の翌月からなので今回は使えない（△）
  - 日本で作る商品は最短3日で届く ✅（[出典](https://www.printful.com/jp/united-athle-products)）
- [ ] 👤 届いたら確認する
  - [ ] 明るい場所で写真を撮る（正面・アップ・着用）
  - [ ] 線のくっきり度、色（特に赤・黄・緑）、プリントの大きさ
  - [ ] 生地の厚さ・肌ざわり・サイズ感
  - [ ] 洗濯を3回して、ひび割れや色落ちを見る
- [ ] 🤖 写真を見せてもらえれば、改善点を一緒に整理します

## 段階4: 人に見せる（費用 0円）
- [ ] 👤 10人くらいに見せる（友人・知人、SNS）
- 聞くこと（私が質問文を作れます）
  1. このデザイン、どう思う？（良い所／気になる所）
  2. 6,980円なら買う？ 買わないなら、いくらなら買う？
  3. 白と黒どっちがいい？
- 注意:
  - 友人は優しく答えがち（推測）。「買う」と言った人に、実際に予約してもらえるかが一番正確
  - ⚠ 人に見せる前に確認すること:「since 1960」の表記、顔のデザインの元ネタ、「Winey」の商標

## 判断
| 結果 | 次にやること |
|---|---|
| 合格 | BASEを開いて、Printfulと連携し、販売開始（CHECKLIST.md の5〜7） |
| 修正 | 直してから、段階2（画面）か段階3（実物）をもう一度。直す所が印刷だけなら画面で確認、生地なら実物でもう一度 |
| やめる | 別のデザインで段階1から |

## 目安の日数（推測）
- 段階1: 元のファイルがあれば1日。清書が必要なら数日〜
- 段階2: 1〜2日
- 段階3: 注文から届くまで約1週間＋洗濯テスト数日
- 段階4: 1週間

**合計 約2〜4週間、費用 約7,700円（サンプル2枚）**
