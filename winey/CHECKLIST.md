# Winey 販売開始までのチェックリスト

記号: ✅ 公式で確認済み / ⚠️ 未確認・推測 / 💰 お金がかかる / 👤 あなたが判断・操作する
（確認日 2026-10-23。料金や仕様は変わることがあります）

## 先に知っておくこと（順番に関わる大事な点）
- ⚠️ Printful の**サンプル割引（20%引き）は「ネットショップを連携済み」の人が対象**で、**連携した翌月から**使えると案内されています（ヘルプセンターの検索結果より。本文は直接読めなかったので確信度 中）
- つまり、ご希望の順番「サンプル注文 → BASE開設 → 連携」だと**割引は使えない**可能性が高いです
- 私の提案: **割引は気にせず、先に定価でサンプルを1〜2枚頼む**（A案）
  - なぜ: Tシャツは「$8.50から」（Printful公式）なので20%引きでも差は1枚あたり数百円程度（推測）。1か月待つより、早く生地を確かめる方が価値が大きい
  - ⚠️ ただし「連携なしで普通の注文（手動注文）ができるか」はヘルプの題名から推測で、**未確認**。登録後の画面で確認します
- B案: BASE開設 → 連携 → 翌月に割引でサンプル。安いが1か月以上遅れる

## 1. Printful に登録する 👤
- [ ] printful.com/jp でアカウント作成（✅ 登録・月額は無料、注文時のみ支払い。[出典](https://www.printful.com/jp/integrations/base)）
- [ ] 支払い方法（クレジットカード等）を登録 💰 ← 登録自体は無料だが、カード情報を入れるのであなたが操作
- 判断すること
  - [ ] どのメールアドレス・名前で登録するか（ブランド用のメールを作るか）

## 2. ボディ（無地のTシャツ本体）を選ぶ 👤
- [ ] 半袖を1種類、ロンTを1種類選ぶ
- [ ] 「日本で製造・発送される商品か」を確認
  - ✅ Printfulは日本の提携工場と組んでいる（鹿嶋・天草。2022年の公式発表）。日本ブランド United Athle も扱いがある（[出典](https://www.printful.com/news/printful-launches-base-integration-in-Japan)）
  - ⚠️ **どの商品が今、日本製造か**は未確認。商品ページの「製造場所」表示やカタログの絞り込みで確認する
  - ⚠️ 日本製造でない商品は海外から届くため、日数と送料が増えると考えられる（推測）
- [ ] 白ボディがあるか、サイズ展開（S〜XL など）、生地の厚さ（oz）を確認
- [ ] 印刷範囲（12×16インチか15×18インチか）を商品ページで確認
- [ ] 原価と日本向け送料を [利益計算表](pricing/Winey_利益計算.xlsx) に入れる
- 判断すること
  - [ ] 生地の厚さ（厚手＝高級感、薄手＝夏向き・安い）
  - [ ] 原価から見て、売りたい値段で利益が出るか

## 3. デザインを入稿する
- [ ] デザイン画像を `winey/design/original/` に入れる（またはチャットで送る）👤
- [ ] 私が透明PNGに変換 → プレビューで確認（[説明](design/README.md)）
- [ ] Printfulの画面で配置・大きさを決める（モックアップ＝着用イメージ画像で確認）
- 判断すること
  - [ ] 胸の大きさ（約38cm幅いっぱいか、小さめか）
  - [ ] 線がぼやけていたら、撮り直し／トレースのどれにするか
  - [ ] 人物3人が実在の人に似ていないか、「Winey」「one love」の商標チェックをするか

## 4. サンプルを注文する 💰👤
- [ ] 半袖1枚・ロンT1枚（自分のサイズ）
- [ ] 届け先を自分の住所にする
- [ ] 届いたら確認: 生地の厚さ・透け、印刷の色、線のくっきり度、洗濯後の変化、サイズ感
- 判断すること
  - [ ] A案（定価ですぐ）か B案（連携後に割引）か
  - [ ] 仕上がりがダメならボディ変更・デザイン修正をするか
- ⚠️ 費用は未確認（原価＋送料。注文画面で確定額が出るので、そこで私が金額を報告 → あなたが承認）

## 5. BASE でショップを開く 👤
- [ ] thebase.com でショップ作成（✅ スタンダードプランは月額0円。[出典](https://thebase.com/price/)）
- [ ] ショップ名・ロゴ・説明文（私が下書きできます）
- [ ] 特定商取引法に基づく表記（ネット販売で法律上必要な、販売者の名前・連絡先などの表示）を設定
  - ⚠️ 自宅住所・電話番号を公開しない方法がBASEにあるかは**未確認**。BASE公式ヘルプで確認する
- [ ] 売上の振込先口座を登録
- 判断すること
  - [ ] プラン: 最初はスタンダード（月額0円）を推奨。✅ グロースは月額 16,580円（年払い）/19,980円（月払い）で、決済手数料が2.9%に下がりサービス利用料0%（[出典](https://thebase.com/price/)）。月の売上が小さいうちはスタンダードが得（推測・確信度 高）
  - [ ] 送料をお客さんからもらうか、値段に含めて「送料無料」にするか

## 6. BASE と Printful を連携する 👤
- [ ] Printfulの画面から BASE を接続（✅ 日本在住の人のみ利用可。[出典](https://www.printful.com/jp/integrations/base)）
- [ ] 商品（半袖・ロンT）をBASEに送る。✅ 商品の自動追加に対応
- [ ] BASE上で値段・説明・サイズ表を整える
- ⚠️ 連携時の「変動制の配送料金」は**未対応**と表に書かれている → 送料はBASE側で自分で設定する必要がある（推測・確信度 中）
- 判断すること
  - [ ] 販売価格（利益計算表で「赤字にならない最低価格」を見て決める）
  - [ ] 送料の設定方法

## 7. 販売開始前の最終チェック 👤
- [ ] 自分で1回テスト購入して、注文 → Printful に自動で届く → 発送まで流れるか確認 💰
  - ✅ 注文が入ると製造〜発送は自動で処理（承認不要）（[出典](https://www.printful.com/jp/integrations/base)）
  - ⚠️ Printful の支払い用カードの残高・限度額に注意（売れるたびにPrintful代を先に払う仕組み。推測・確信度 中）
- [ ] 返品・交換のルールをショップに書く（不良品はPrintfulに相談できるか ⚠️未確認）
- [ ] 公開ボタンを押す 👤
- [ ] SNS（Instagram 等）で告知するか判断 👤
