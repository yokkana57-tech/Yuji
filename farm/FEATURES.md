## 農家さん向け（下のタブ「農家の方」）

| 機能 | 内容 |
|---|---|
| 農園の登録 | 農園名・想い・育て方・写真・畑の位置・売るもの（価格・在庫・お届けできる月） |
| 販売者情報 | 氏名（公開）・電話・住所（非公開。請求があれば運営が開示） |
| 受け取りの設定 | 曜日・時間・住所（必須。注文した人だけに表示。公開するかは選べる）・現金払いの受け付け |
| 発送の目安 | 注文から何日以内に発送するか（特商法の表記と注文手続きに表示） |
| 受け取り口座 | Stripe で本人確認と口座登録（カード払い・配送に必要。現金払いだけなら不要） |
| 注文の管理 | 準備できた／発送した／番号で受け渡し完了／来なかった（現金払い）／メッセージ |
| お手伝いの募集 | ボランティアを募集し、申し込みを受け入れる／見送る。メッセージで連絡 |
| お店の相談 | 受け付けをオンにすると、お店からの相談が届く |
| 口コミへの返事 | 自分の農園のページの口コミに返事を書ける（みんなに表示） |
| 畑だより | 写真つきで投稿 |
| なかま市 | 農家どうしで農具・資材をゆずる／売る／ほしい。出品できないもの（農薬など）の確認つき |

## お金のルール

- 運営の手数料は0円。
- カード払いのときだけ、Stripe の決済手数料（3.6%）を農家さんの売上から差し引く（サーバーの `PLATFORM_FEE_PERCENT=3.6`）。
- 現金払いの予約・お店との取引・お手伝いには、手数料もお金のやりとりもない。

## 安全・リスク対策

| 対策 | 仕組み |
|---|---|
| 他人の情報を読めない | データベースの行単位の権限（RLS）。注文・メッセージ・お手伝いの申し込み・お店の相談は、当事者だけが読み書きできる |
| 価格の改ざん防止 | 価格・在庫・受け取り日時はサーバー側（`create_order`）で計算・確認する |
| 支払われない注文の後片付け | 45分たっても支払われない注文を、10分ごとに自動で取り消して在庫を戻す（pg_cron） |
| 来ない予約への対策 | 現金払いで来なかった予約が2回になると、現金払いの予約ができなくなる。同時予約は3件まで |
| 連投の制限 | 声・メッセージ・お問い合わせ・お店の相談などに1日の上限 |
| 質問箱の使いすぎ防止 | 1人（ログインしていなければ通信元ごと）1日20回、アプリ全体で1日2000回まで（`ai_take`）。質問の中身は保存しない |
| エラーの記録 | 画面のエラーを `client_errors` に記録（個人情報なし） |
| サーバーの停止防止 | Supabase 無料プランの一時停止を防ぐため、毎日アクセスする（`.github/workflows/keepalive.yml`） |
| サクラの口コミの防止 | 口コミはサーバーの関数（`save_review`）からしか書けない。受け取りが完了した注文の本人だけが書ける。農家さん本人は書けない（ステマ規制） |
| 法律 | 利用規約・プライバシーポリシー・特定商取引法の表記（農家さんごと）・加工品とお米の注意・援農はボランティアに限定（職業安定法） |

## 質問箱（AI）のしくみ

- サーバーの処理 `supabase/functions/ask-ai` が Claude（`claude-opus-5-5`、考える深さは「低」）を呼ぶ。キーは Supabase の秘密の値 `ANTHROPIC_API_KEY` に置く（アプリの中には置かない）。
- AI に渡す「説明書」は、`help.js`（使い方ガイド・よくある質問）から `scripts/build-ai-knowledge.mjs` で作る。help.js を直したら、このスクリプトを実行して ask-ai を公開しなおす（`setup-backend.mjs` が自動で行う）。
- AI の答えは説明書にあることだけ。注文ごとのことは、注文画面のメッセージかお問い合わせに案内する。
- 安全の判定で答えられなかったときは、Anthropic がすすめる別のモデルで答えなおす（server-side fallback）。
- `ANTHROPIC_API_KEY` がないとき・AI が止まっているときは、画面側でよくある質問から探して答える。
