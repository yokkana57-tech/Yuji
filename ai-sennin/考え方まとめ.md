## 1. 根っこにある考え方（7本すべてに共通）

1. **AIに任せる。ただし丸投げはしない**
   人間がやるよりAIの方がミスが少ない作業は任せる。でも出てきたものを確認しないまま人に渡すのは最悪。
2. **AIは使った分だけ上手くなる（語学と同じ）**
   毎日少しずつ。間が空くと腕が落ちる。
3. **コンテキストが命**
   コンテキスト＝「AIは知らないけど自分は知っている、その仕事に関する情報ぜんぶ」。AIが使えないと言う人は、たいていこれを渡していない。
4. **ツールは追わない。土台を作る**
   ツールの使い方はすぐ古くなる。必要になったときに覚えればいい。土台（言葉にする力・コンテキストの集め方・評価する目）があれば、新しいツールには数時間で追いつける。
5. **目的が先、情報は後**
   やりたいことがない情報集めは時間の無駄。小さい目的でいいので持つ。
6. **判断は自分でする**
   AIはもっともらしい理由をいくらでも作れる。「AIが言ったから」で動かない。

## 2. 段階別にやること

### 初心者
- Google検索の代わりにAIに聞く（1日10回が目安）
- **音声入力**で30秒しゃべり切る。言い間違いは気にしない（AIが察してくれる）。場所や数字など、事実の間違いだけ直す
- 自分の情報（メール・議事録・LINE履歴など）を入れて相談し、「便利だ」と驚く経験をする
- テーマごとにチャットを分ける。長くなって返事がおかしくなったら新しいチャットへ
- 「1回でいいから有料版の強いモデルにコンテキストを入れて、本気の悩みを相談してみて」
- ChatGPTが賢くないと感じたら、モデル選択がデフォルトのままになっていないか確認する

### 中級者
- **指示の最低3点セット**：①目的（何のためか）②アウトプットの形（HTML・表・箇条書きなど）③手段・制約（この材料を使う、この方法はダメ）。できれば④インプット（使うデータ）も入れる
- 丁寧に書きすぎない。「とりあえず100個出して」→良さそうなものを深掘り、で十分
- 大きすぎる仕事は「タスクを分解して」とAIに頼み、小さい単位で進める
- 1つの仕事に1つのフォルダ。関係ないファイルが入っていると、AIがそれを読んで間違える
- 順番に進めるフォルダは名前の頭に 01, 02… と番号を付ける
- 設定ファイル（AGENTS.md など）は短く（10〜15行程度）。毎回必ず守るルールだけ書く
- スキルやMCP（AIと外部サービスをつなぐ仕組み）を入れすぎない。使わないものは外す

### 上級者
- **並列で動かす**：AIが作業している間に待たず、別のAIに別の仕事を頼む
- **裏で自動で動く仕組み**（例：届いたメールを要約してLINEに送る）を少しずつ増やす
- ただし**完全自動化はいきなりやらない**。まず手作業で（AIと一緒に）1つちゃんとしたものを作る → それから自動化
- 1〜2週間やってもできないことは、AIの性能が足りないと考えて一度寝かせる。次のモデルで再挑戦

## 3. やってはいけないこと

| NG | 理由 |
|---|---|
| AIの出力を確認せず人に渡す（ポン出し） | 相手に確認作業を押し付けることになるし、自分も成長しない |
| 「AIが言ったから」で決める | AIはどんな結論にも理屈を付けられる |
| 目的のない情報集め・驚き屋の真似 | 今使わない知識は1年後には古くなっている |
| いきなり全自動化 | 質の低いものが大量にできるだけ |
| セキュリティを「全部ゆるい」か「全部怖い」で考える | どこが本当に危ないかを分けて考えるべき |
| 変化を拒む | 新しい道具を嫌っても、時代の流れは止められない |
| 勝負どころでAIの出力をそのまま出す | 見る人が見ればAIっぽさに気づく。大事な場面ほど自分の手を入れる |

### セキュリティの線引き（動画7より）
- **自分の**名前などをAIに入れるのは、すでにGoogleなどに預けている情報と大差ない
- **お客さんの**個人情報や、秘密保持契約（NDA）で守るべき情報を入れるのは危険
- 「入力をAIの学習に使う」設定は**オフにする**
- 会社が許可していないAIに会社の情報を入れない
- 素人がAIで一般向けのWebサービスを作って公開するのは危険（個人情報が漏れる例がある）

## 4. AIの出力を評価する力（動画4）

- 一番強いのは、**自分が詳しい分野**でAIを使うこと
- 詳しくなくても、**目的と良し悪しの基準**が分かる分野ならOK（作り方は分からなくても、出来上がりの良し悪しは判断できる）
- 目的も基準も分からない分野はNG
- 判断を鍛えるための質問の型：
  1. この案の前提を整理して
  2. その前提が違っていたら、結論はどう変わる？
  3. 弱点・見落とし・反対意見は？
  4. 他の案と比べるとどう違う？
  5. 一次情報で確認すべき点は？
  6. 間違っていた場合のリスクは？

## 5. 差がつく習慣10（動画6）

1. 毎日AIと話す（音声で。仕事以外の話題でもいい）
2. 自分の悩みをAIに分解してもらい、選択肢を出させる
3. 目的のない情報集めをやめる
4. コンテキストを集める（会議の録音→文字起こしなど）※今後いちばん大事
5. 欲しいツールをAIに作らせる（何を作るかもAIに聞いていい）
6. AIの出力を速く読む練習（知っている分野はざっと読む）
7. 「AIパズル」：うまくいっている例の仕組みを取り出して、自分の分野に当てはめる
8. 並列で動かす
9. 裏で自動で動く仕組みを作る
10. AIが好きだと周りに話す。人の悩みをAIで解決しようとすると一番伸びる
